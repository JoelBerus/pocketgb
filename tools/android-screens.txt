# Formato: <id> <portrait|landscape> <light|dark|dyn-green|dyn-violet> [clave=valor ...]
#   - Una línea por captura; un mismo id repetido (otro tema) debe llevar la misma orientación y los mismos argumentos.
#   - Los argumentos se pasan a la app como extras de texto (DebugIntent; `fontScale` como Float). Son solo del script y no llegan a la app:
#     `wait=<s>` (espera extra), `swipe=up` (desplazar antes de capturar), `window=wide` (A7: pantalla de 1280x800 a 240 dpi, 853 dp de
#     ancho, para el NavigationRail y el lista-detalle; la orientación del manifiesto no gira la pantalla) y `cutout=tall` (A7: recorte
#     de pantalla simulado con el overlay del sistema; sin él el ID se omite con aviso en un AVD que no lo tenga).
#   - El juego va siempre oscuro (K4): sus ids solo tienen la variante dark.
#   - dyn-green / dyn-violet: color dinámico con semilla fija (Android 12+), en tema claro.
