## Auditoría Codex ([M9-codex.md](M9-codex.md))

| ID | Estado | Corrección y evidencia |
|---|---|---|
| H1 (alta) | corregido | La pasada de validación de `gb_state_load` limita `cycles` a `INT64_MAX`, antes de aplicar ningún campo. `state_cycle_limit` fabrica un estado con `cycles = INT64_MAX + 1`, exige `GB_ERR_STATE_CORRUPT`, comprueba que la instancia no cambia y después ejecuta `gb_link_attach`/`gb_link_run_cycles`. La prueba falló antes de la corrección y pasa en la suite normal y bajo ASan+UBSan. |
| H2 (media) | corregido | Cada `gb` mantiene un `state_load_epoch` interno y no serializado; cada puerto recuerda el epoch con el que calculó su `offset`. Una carga exitosa cambia el epoch y fuerza el realineado en el siguiente avance, incluso dentro de la antigua ventana heurística. `state_realign_case` cubre T+45, T+500 y T+912 y comprueba tras el primer bloque que ambos lados avanzaron el bloque completo y que la deriva entre sus avances es ≤44. Las mutaciones previas produjeron cuatro fallos; con el epoch pasan. `fuzz_link` también renueva su origen lógico tras carga/recarga/reconexión y vuelve a comprobar lockstep desde el primer frame. |
| H3 (baja) | corregido en código; campaña de 600 s bloqueada por el entorno | Las seis semillas largas de `f1cec9f` siguen presentes (cinco de 86 bytes y una de 98; 536 bytes totales con la semilla corta). Se añadió `make -C core fuzz-link`, que compila solo este harness con ASan+UBSan y ejecuta exactamente `-max_total_time=$(FUZZ_SECONDS) -max_len=16384 -len_control=0`. El harness compila sin warnings. La campaña solicitada no pudo arrancar: Xcode trae Apple Clang sin libFuzzer, Homebrew no tiene `llvm` instalado y la red del entorno no resuelve `formulae.brew.sh`, por lo que no fue posible descargar la botella. |

Verificación local del cambio: `make -C core test HITO=M9` y `make -C core asan HITO=M9` dieron **157/157 requeridos PASS** (`unit`: 1337 comprobaciones, 0 fallos); `make -C core check-globals` dio **Sin estado global mutable: OK**. El intento de `make -C core fuzz-link FUZZ_SECONDS=600 CC=clang` terminó antes de compilar con `Este clang no trae libFuzzer (el de Apple no lo incluye)`.
